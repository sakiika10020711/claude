# ASD 対人相互作用 文献学習 — フェーズ1

自閉スペクトラムの対人相互作用に関する文献を、当事者の立場から実践的な
方法論に落とすための学習リポジトリ。

## 運用方法

**11単元を11本の独立したチャットで扱う。状態はチャット履歴ではなくこの
リポジトリのファイルが持つ。** 詳細は [`00_運用ガイド.md`](00_運用ガイド.md)。

## 構成

```
00_運用ガイド.md        方式・順序・エージェントの使いどころ
10_briefing/            単元ごとのブリーフィング（コピペ用プロンプト入り）
  共通ブリーフ.md         毎回冒頭に貼る15行
  A_二重共感問題.md       Milton 2012 / Crompton 2020, 2025
  B_相手側の要因.md       Sasson 2017, 2019 / Morrison 2019 / DeBrabander 2019
  C_スキル訓練.md         Laugeson 2015 (PEERS)
  D_カモフラージュ.md     Cage & Troxell-Whitman 2019 / Mandy 2019 / van der Putten 2025
  M1_ゴールの再定義.md    ← A
  M2_チャネル選択.md      ← B
  M3_メタ情報.md          ← B
  M4_明示的スキル.md      ← C
  M5_自己評価の較正.md    ← B
  M6_場の選択.md          ← A, B
  M7_コスト設計.md        ← D
20_notes/               各セッションの持ち帰りノート（A4一枚）
30_synthesis/           11枚を統合する最終セッション
```

## 注記

各ブリーフィングに含まれる書誌情報は、出発点となった議論から引き写したもの。
`【要確認】` と付いた箇所は、当該セッション内で一次資料に当たって確定させる。
